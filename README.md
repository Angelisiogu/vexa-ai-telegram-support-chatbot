# vexa-ai-telegram-support-chatbot

AI-assisted Telegram support chatbot workflow built with Zapier and AI integrations. 
Live Demo
Try the Vexa AI Telegram Support Chatbot: Open Telegram Bot
https://t.me/Vexa_AssistBot

## Key Features

- Automated Telegram message handling.
- AI-assisted responses to user enquiries.
- Workflow steps managed through Zapier.
- Typing indicator to make interactions feel more natural.

## How It Works

1. **Telegram Trigger:** Detects an incoming message.
2. **Storage by Zapier:** Manages conversation or workflow data.
3. **Delay:** Allows a short pause in the workflow.
4. **AI by Zapier:** Processes the message and generates a support response.
5. **Telegram Response:** Sends the generated reply back to the user.

## Tools & Technologies

- Telegram Bot API
- Zapier
- AI by Zapier
- Storage by Zapier
- Webhooks/API for the typing indicator

## Lessons Learned

This project helped me practise connecting multiple tools into one workflow, organizing automation steps, integrating AI into a support process, and improving the user experience through a typing indicator.
